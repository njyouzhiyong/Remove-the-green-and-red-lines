# Remove the green and red lines

## 结论

用软件遮盖手机屏幕上出现的红线 / 绿线，不可行。

这类线通常不是系统或应用层的问题，而是屏幕硬件损坏的表现：排线接触不良、显示驱动异常，或者像素点 / 子像素本身失效。软件只能在画面上再盖一层遮罩或滤镜，看起来像是“挡住”了线，但并没有修复损坏的硬件。实际使用中还可能带来耗电、显示延迟、亮度 / 色彩异常，甚至影响系统稳定性。

## 为什么留下这个仓库

这个想法我已经验证过了，结论是不值得继续做。把仓库留在这里，只是记录一下这个灵感，避免后人（包括未来的我）再花时间走同一条弯路。

当然，我也可能是错的——这只是目前的结论。所以这个仓库还有另一个作用：作为一个讨论的入口。如果你有不同的思路、新的发现，或者认为我判断错了，欢迎开 issue 一起讨论。

本项目本身不再维护，也不接受“用软件修复坏线”的 PR。

## 建议

如果屏幕出现红线 / 绿线，建议：

- 先备份重要数据；
- 联系售后或维修点检测排线 / 屏幕；
- 在保修期内优先走官方维修；
- 必要时更换屏幕模组。

如果你正在找“用软件修复屏幕坏线”的办法，这里可以帮你省下时间：目前看来没有可靠的软件解法，但欢迎来讨论。
